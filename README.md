# Hotline Camp — Сочи 2026

Лендинг триатлонного кэмпа Hotline в Сириусе, 27 сентября — 4 октября 2026 года.

## Что внутри

- программа и ритм предстартовой недели;
- текущая погода в Сочи, море, рассвет/закат и прогноз на даты кэмпа из Open-Meteo;
- тренеры Евгений Тихонин и Максим Кубышко;
- светлая и тёмная темы;
- четыре одинаковых CTA «Заполнить заявку», ведущих в Google Forms;
- сохраняемые настройки темы и движения в меню;
- чистая статическая публикация через GitHub Pages.

## Локальная разработка

Сборка и Node.js не нужны. Исходник сайта находится в `public/`.

```bash
python3 -m http.server 3000 --directory public
```

После запуска сайт доступен на `http://localhost:3000/`.

Контракт страницы проверяется стандартной библиотекой Python, без сторонних
зависимостей:

```bash
python3 scripts/check_static.py
```

## GitHub Pages

Workflow `.github/workflows/pages.yml` проверяет статический контракт и
публикует папку `public/` без шага сборки. Единственный настроенный канал
публикации остаётся прежним: GitHub Pages Actions.

## Прогноз и экономия ресурсов

До 17 сентября показывается дата начала прогноза. Затем запрашивается горизонт
до 16 дней: ячейка называет только непрерывный доступный диапазон дат кэмпа,
минимальную и максимальную температуру за него. Неполный диапазон помечается
«часть дат»; ошибка и завершение кэмпа имеют отдельные состояния. Источник:
[Open-Meteo](https://open-meteo.com/en/docs). При возврате на вкладку данные
обновляются, если прошло 30 минут.

WebGL-поле приостанавливается вне экрана и в скрытой вкладке; фавиконка —
в скрытой вкладке. Режим без движения оставляет статичный кадр.
Фотографии используют `srcset` без изменения утверждённых кадров. Оригиналы
сохранены; копии шириной 480 и 960 px воспроизводятся командой
`sh scripts/prepare_images.sh` на macOS (системный `sips`, без сборки сайта).

Для браузерных регрессий запустите сервер из корня репозитория и откройте
`/scripts/check_browser.html`: проверки используют настоящий `public/app.js`,
а тестовые погодные данные никогда не попадают в публичную папку.
